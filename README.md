## ⚡ Key Features

- **Cinematic Muse-Style Cold Launch**: Dynamic spiritual reiatsu aura, sleek kinetic typography, and fluid launch transitions.
- **Seanime Tenji Aesthetic**: Deep void dark interface (`#090A0F`) with crimson neon spiritual accents designed for high-end OLED displays.
- **Zero-Bandwidth Streaming Engine**: Multi-server failover system featuring:
  - *Bankai • Koto* (Direct CDN)
  - *Shikai • Zone* (Fast Buffer)
  - *Tsukuyomi* & *Kamui* (Multi-Resolution 1080p / 720p / 360p)
  - *Chidori* (Hindi Dubbed Streaming)
- **Universal Subtitle Engine**:
  - WebVTT & SubRip (SRT) parser
  - Live time offset calibration (±0.5s Earlier/Later) to fix desynced subtitles on the fly
  - Multi-language subtitle tracks
- **Integrated Manga & Manhwa Reader**:
  - Vertical Webtoon infinite scroll & Horizontal pager modes
  - High-res GPU image tile renderer
- **In-App Auto Updater**: Instant 1-click updates pulled directly from this repository without needing to visit third-party stores.
- **120Hz / 144Hz Refresh Rate Support**: Synchronized with Android Choreographer for buttery smooth scrolling.
